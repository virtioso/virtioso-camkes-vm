### 2. Isengard Yocto/Rust build consolidation

**Why it matters:** The Yocto `externalsrc` recipes did not handle the cargo workspace correctly:
`do_compile` was building against the wrong `--target-dir`, and `do_install` was looking for
binary names that no longer matched after the crate rename. This caused silent wrong-binary
installs and intermittent build failures — a blocker for any CI-backed image delivery.

**Done:**
- `isengard-app-crates.inc` (1,257 lines) and `isengard-zenoh-bridge-crates.inc` (461 lines)
  generated from `cargo.lock` — required by the `cargo` Yocto class for offline builds
- `do_compile` fixed to use `oe_cargo_build --workspace` with explicit `--target-dir`
- `do_install` binary names corrected to match renamed crates
- Additional fixes: pkgconfig inherit for fuse build script, bytemuck/bytemuck_derive added to zenoh-bridge crates.inc, last lock entry (zmij) parsing bug fixed
- `libstd-rs` replaces `rust-staticdev` in `isengard-image-base`
- `kernel-module-fuse` removed from `isengard-app` RDEPENDS (not needed for container target)

**Commits:** `2a22187`, `9955d69`, `cf93799`, `2e3b9cf`, `0853041`, `c578a2c`, `05e0e62`, `8352384`, `5bf45ce`, `fb73acc`, `78240fb`

### 4. iceoryx2 feasibility study

**Why it matters:** The current inter-component IPC in Isengard is ad-hoc shared-memory Rust
(N-buffer / topic-broker pattern). iceoryx2 provides zero-copy publish/subscribe over shared
memory with a well-maintained API, and could replace the custom solution. The study gates the
decision: do we invest in a PoC or stay with our own code?

**Done:**
- `docs/architecture/studies/iceoryx2.md` expanded from stub to 351 lines
- Covers: iceoryx2 communication patterns (pub/sub, request/reply, blackboard service), Zenoh
  tunnel (bridging to external networks), fit vs. N-buffer/topic-broker, seL4/CAmkES IPC
  compatibility constraints, estimated PoC effort (8–14 weeks)
- Initial feasibility file added (`7629d3e`), then major expansion (`19f789d`)

**Commits:** `7629d3e`, `19f789d` (isengard-core)

**Status:** Study complete. Decision on whether to proceed to PoC is open — needs team discussion.
