# Documentation Structure

This documentation is organized by purpose and audience. Please place new documents in the most appropriate category and keep cross-links relative.

## Start Here
For first-time users and day-1 workflows.
- `start-here/`

System-level design, protocols, and models.
- `architecture/`

## Components
Component-level behavior and interfaces.
- `components/`

## Integration

- `integration/`
